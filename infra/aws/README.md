# AWS infrastructure

Khu vực dành cho IaC và môi trường AWS dự kiến: CloudFront/S3 cho web, Cognito, API Gateway/Lambda, S3 raw/reports, EventBridge, SQS/DLQ, DynamoDB, Secrets Manager và CloudWatch.

Chưa chọn công cụ IaC hay cấu hình triển khai. Không commit state, secret, account ID hoặc dữ liệu khách hàng.
